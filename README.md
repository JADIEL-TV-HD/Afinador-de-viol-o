# JADIEL PLAY

Afinador real de instrumentos no navegador.

- Detecção de pitch por autocorrelação.
- Microfone processado localmente no navegador.
- Violão, baixo, ukulele, violino, viola, violoncelo, bandolim, cavaquinho e modo cromático.
- Medidor de cents e indicação de grave/agudo/perfeito.
- Interface responsiva com animações e visual 3D em CSS.
- Sem banco de dados, PHP ou API.
- Compatível com hospedagens estáticas como InfinityFree.

## Uso
Abra o site em HTTPS, permita o microfone e toque uma corda/nota isoladamente. Ajuste até o ponteiro ficar no centro.

O áudio não é enviado para servidor: o processamento da afinação acontece localmente no dispositivo.
